# Shift Hours

A small tool for calculating shift hours — how long you've worked, how much is left, and when you can clock out.

**Live:** https://mayurathod-ui.github.io/Shift-Hours/

## How to use

1. Copy your attendance/punch log (any text containing times like `9:41:12 AM`).
2. Paste it into the page and press **Calculate**.

Everything runs in your browser. Nothing is uploaded, stored or sent anywhere, and no login or token is needed.

Personal project, public for hosting convenience.
